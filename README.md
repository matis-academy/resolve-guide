# Интерактивный справочник DaVinci Resolve 21

Наведите мышь на любую кнопку интерфейса — элемент подсветится, рядом появится карточка: что это, когда пригодится, горячая клавиша.
Страницы: **Edit**, **Color**, **Deliver** (две прокрутки настроек рендера). Поиск по названиям и описаниям, режим «Все зоны», список всех элементов по группам, ссылки на конкретный элемент (`#edit/edit.blade`).

## Как устроено
- `index.html`, `style.css`, `app.js` — сайт без сборки и зависимостей.
- `img/*.webp` — скриншоты страниц Resolve 21, 2560×1032 (кадры с людьми и путь к папке пользователя размыты). Разметка `box` — в системе координат 2000×806 (`w`, `h` вида в data), картинка может быть любого размера с теми же пропорциями.
- `data/<страница>.json` — зоны элементов: `box: [x, y, w, h]` в пикселях скриншота, `en` — название как в Resolve, `ru`, `what`, `use`, `keys`, `kind: panel|control`, `unsure` — назначение уточняется, `src: knowledge|manual` — черновик или сверено с DaVinci Resolve 21.1 Reference Manual, `manual` — номер страницы руководства (печатный).
- `data/common.json` — главное меню и панель страниц, общие для всех скриншотов.
- `tools/grid.py` — увеличенный фрагмент скриншота с координатной сеткой (для разметки), `tools/boxes.py` — проверка разметки рамками, `tools/test.mjs` — автотест в браузере (Playwright).

## Добавить страницу
1. Скриншот всего окна Resolve → `img/<page>.webp`.
2. Разметить зоны в `data/<page>.json` (координаты снимать через `tools/grid.py`, проверять через `tools/boxes.py`).
3. Добавить страницу в `PAGES` в `app.js`.

Запуск локально: `python3 -m http.server 8766` в папке проекта → http://127.0.0.1:8766/
